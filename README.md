# Translate JSON Project

โปรเจคนี้เป็นสคริปต์ Python สำหรับแปลไฟล์ JSON จากภาษาหนึ่งไปยังอีกภาษาหนึ่ง โดยใช้ `deep_translator` และรองรับการประมวลผลหลายไฟล์พร้อมกัน

## วิธีรันคำสั่งก็คือ 
python -m scripts.translate_json
ไม่สามารถกดรันได้โดยตรง ต้องใช้คำสั่งนี้เท่านั้น
